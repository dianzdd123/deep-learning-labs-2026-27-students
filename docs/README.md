instructor material are not part of this public student route.

The [teaching page](https://www.intelligentrobotics-acrossscales.com/teaching) provides
the course introduction, lecture materials, handbook/video previews, Main labs and
optional Additional sessions. Use Canvas for current assessment documents and
submissions, and the separate [Part A repository](https://github.com/dianzdd123/2026-2027-Deep-Learning-Final-Coursework-Part-A)
for the released coursework dataset. For student course access, contact Dr Dandan
Zhang at [d.zhang17@imperial.ac.uk](mailto:d.zhang17@imperial.ac.uk).
