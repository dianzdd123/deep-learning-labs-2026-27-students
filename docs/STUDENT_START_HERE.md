You will complete four **unmarked practice labs**: CNN, ResNet, RNN and Transformer.
Each has a Keras/TensorFlow worksheet and a PyTorch worksheet. **Choose one framework
for your first attempt. You do not need to complete both versions before moving on.**

The code cells are deliberately empty. You will write the implementation using the
instructions, lecture ideas and documentation. A blank cell is not a download error.

## 1. Choose where to work

| Your situation | Start with | You are ready when |
|---|---|---|
| First time using notebooks; want minimal installation | [Google Colab](ENVIRONMENT_SETUP.md#route-a-google-colab) | You can run a cell and save a personal copy |
| Prefer a local editor and files | [VS Code](ENVIRONMENT_SETUP.md#route-b-local-vs-code-or-jupyterlab) | The notebook kernel points to your project environment |
| Already use JupyterLab | The same [local environment](ENVIRONMENT_SETUP.md#route-b-local-vs-code-or-jupyterlab) | Your notebook and terminal use the same Python |

GitHub stores and displays files. **It does not run the notebook.** Colab or your
local Python kernel runs the code. A local GPU or paid Colab plan is not required
for a small first experiment.

## 2. Complete a short preparation session

Suggested allocation: about 25–35 minutes, with extra time if installing locally.
These are study suggestions, not assessed time limits.

1. **Open and save:** follow the environment guide and create a notebook called
   `practice_setup.ipynb`. Save it in your own Drive or local working folder.
2. **Run a cell:** print a message and your Python version. Read
   [notebook basics](NOTEBOOK_BASICS.md) if cells or kernels are new to you.
3. **Check one framework:** use the small tensor check in the environment guide.
   Explain the shape before running it. There is no model to train at this stage.
4. **Restart and repeat:** restart the runtime/kernel, then run your cells from the
   top. This checks that your work does not depend on hidden earlier state.
5. **Make a learning record:** copy the [learning log](LEARNING_LOG.md) into your
   personal notes. Record the framework and versions you actually used.

**Preparation finished:** you can open, edit, run, restart and save a notebook;
your chosen framework imports; you know where your work is saved.

## 3. Open a worksheet when it is released

Return to the [release table on the homepage](../README.md#weekly-worksheets).
It tracks blank worksheets in this public repository. **Coming soon** means that
worksheet has not been published here; it does not describe the status of lecture
slides, authorised course notebooks or the released Part A dataset. Preparation is
separate from Labs 1–4. If a scheduled worksheet is missing, check Canvas.

For a released lab:

1. Open its lab page and choose **Keras/TensorFlow** or **PyTorch**.
2. Choose **Open in Colab**, or download the `.ipynb` for VS Code/JupyterLab.
3. Save a personal copy, for example `lab1_cnn_keras_mywork.ipynb`.
4. Read the learning aim, dataset description and all exercises before coding.
5. Follow the [lab workflow](LAB_WORKFLOW.md). Work on one exercise at a time.

Released labs also provide an empty `.py` worksheet with VS Code cell markers.
It contains the same instructions as comments. It does nothing until you add your
own code. Use the notebook first if you want plots and explanations together.
